# Лабораторна робота №8. ORM та доступ до даних

**Варіант 17: Система моніторингу виробничої лінії**

## Опис проєкту
Консольний застосунок для обліку типів виробів та виготовлених деталей на виробничій лінії.
Використовує SQLite для зберігання даних та sqlite_orm для об'єктно-реляційного відображення.

## Сутності
* **ProductType** (основна) — тип виробу (назва, категорія, стандартна вага).
* **ManufacturedPart** (залежна) — виготовлена деталь (серійний номер, дата, вага, статус).
Зв'язок: один тип виробу може мати багато виготовлених деталей (1:N).

## Технології
* C++20
* CMake 3.21+
* vcpkg (sqlite3, sqlite-orm)
* SQLite 3
